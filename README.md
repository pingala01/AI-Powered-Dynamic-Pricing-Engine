# AI-Powered Dynamic Pricing Engine

## Easiest way (IDLE)
1. Unzip the folder.
2. Open IDLE, choose File > Open, select run_app.py, press F5.
   It installs missing packages the first time, then opens the dashboard in your browser.
3. To run the tests: open run_tests.py and press F5.

## Normal Command Prompt
    cd path\to\pricing_engine
    python -m pip install -r requirements.txt
    python run_tests.py
    python run_app.py

(The dashboard can also be started with: python -m streamlit run app.py)
data\sample_sales_data.csv is SYNTHETIC demo data. Use the sidebar to upload your own CSV.
